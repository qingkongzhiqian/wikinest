# 统一编辑器实时目录设计

## 目标

在笔记的统一编辑器中恢复正文左侧目录。目录在编辑过程中实时反映二级、三级标题，点击条目可滚动到对应标题。

## 交互

- 宽屏下，编辑器采用“左侧目录 + 右侧正文”两栏布局。
- 目录读取编辑器当前渲染出的 `h2`、`h3`，保持文档顺序，并缩进三级标题。
- 标题新增、删除、改名或层级变化后，目录自动刷新。
- 点击目录项时平滑滚动到对应编辑器标题。
- 少于两个可用标题时隐藏目录，正文恢复居中单栏。
- 视口宽度不超过 1024px 时继续隐藏目录，避免压缩正文。
- 旧的只读正文目录行为保持不变。

## 实现

在统一编辑器容器外增加独立布局容器和目录导航，不复用只读正文的目录节点，避免两个视图互相覆盖状态。

页面控制器在统一编辑器完成载入后扫描其 DOM 中的 `h2`、`h3`。使用一个限定在编辑器根节点内的 `MutationObserver` 监听子树和文本变化；变化发生后通过一次 `requestAnimationFrame` 合并刷新，避免每次输入都重复重建。

目录链接不依赖持久化 ID，而是保存对应标题元素引用。点击后调用 `scrollIntoView`。切换笔记、进入源码后备编辑器或离开正文时断开观察器并清空目录，避免旧节点和监听器泄漏。

## 异常与降级

- 编辑器尚未生成 DOM 时显示单栏；下一帧重新扫描。
- 浏览器不支持 `MutationObserver` 时仍生成首次目录，但不实时更新。
- 标题文本为空时不创建目录项。

## 测试

- 布局测试验证统一编辑器不再隐藏自己的目录布局。
- 目录模型测试验证只收集 H2/H3、顺序与层级正确、少于两个标题时隐藏。
- 页面源码测试验证观察器在编辑器打开时安装、离开时清理。
