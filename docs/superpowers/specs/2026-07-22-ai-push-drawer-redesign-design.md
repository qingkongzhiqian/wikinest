# AI 推开式侧栏重设计

## 背景与已确认问题

当前 AI 请求失败已稳定复现。使用现有通义千问配置和实际笔记发起请求时，上游返回：

- HTTP 429
- 错误码 `limit_requests`
- 原因：工作空间请求频率超限

现有服务端将所有上游错误统一转换为 `AI_EDIT_FAILED`，前端只能显示“请求失败，已保留收到的内容”，用户无法判断是频率限制、配置错误、超时还是网络问题。

当前悬浮卡片还会覆盖正文，导致阅读和编辑空间被遮挡。新版改为右侧推开式侧栏。

## 目标

- 桌面宽屏下从右侧推出 AI 面板，同时让主内容区域缩窄，不覆盖笔记。
- 保留多临时会话，但把会话管理收进顶部菜单。
- 有选区时默认仅发送选区；无选区时发送当前文档。
- 将安全的上游错误分类为可操作反馈，不泄露 API Key、provider 原始响应或敏感内容。
- 简化视觉层级，让输入和回答成为界面重点。

## 桌面布局

### 收起状态

- AI 入口位于窗口右边缘中下部，使用窄圆角标签或图标按钮。
- 入口固定在应用壳层，不随正文滚动。
- 未配置 LLM 时入口保持可聚焦，通过可访问提示说明需要配置。

### 展开状态

- 应用主体使用两列布局：`主内容 + AI 侧栏`。
- AI 侧栏默认宽度 380px，允许在 320px 到 560px 之间拖动左边缘调整。
- 主内容占据剩余空间，保持自己的滚动位置，不被侧栏覆盖。
- 侧栏打开和关闭使用短距离宽度动画；遵循 `prefers-reduced-motion`。
- 用户调整后的宽度仅保存在当前页面运行期间，不写入 Vault 或同步。

### 窄窗口

- 当可用宽度不足以同时展示正文和 320px 侧栏时，切换为独立助手视图。
- 独立视图替代当前主内容，而不是叠加半透明抽屉。
- 关闭助手后恢复原页面及滚动位置。

## 面板结构

### 顶部

- 左侧菜单按钮打开临时会话列表。
- 中间显示当前会话标题。
- “新聊天”创建并切换到空会话。
- 右侧关闭按钮收起侧栏。

### 会话菜单

- 展示当前运行期间的临时会话，按最近更新时间排序。
- 支持切换和删除。
- 切换或删除正在生成的会话会取消请求，并保留已收到内容为“已停止”。
- 会话刷新页面或退出应用后消失，不写入 Vault、不参与对象存储同步。

### 对话区

- 空会话仅显示少量、与当前上下文匹配的快捷建议。
- 有消息后隐藏大面积引导内容，把空间用于对话。
- 模型输出按纯文本 Markdown 展示，不直接注入 HTML。
- 生成中、完成、停止和失败通过独立状态区域播报。

### 输入区

- 输入区固定在侧栏底部。
- 上方显示一个紧凑上下文标签：
  - `选区 · N 字`
  - `当前文档 · 标题`
  - `无文档上下文`
- Selection 模式可显式选择“附带全文”，默认关闭；离开精确选区上下文立即重置。
- Enter 发送，Shift+Enter 换行；生成时显示停止按钮。

## 上下文规则

发送前捕获一次不可变上下文快照，界面提示和请求载荷共同使用该快照：

1. 编辑器存在非空选区：`selection` 模式，默认仅发送选区。
2. 没有选区但存在当前笔记或编辑草稿：`document` 模式，发送当前 Markdown。
3. 没有当前笔记：`general` 模式，不发送任何 Vault 内容。

Selection 模式的完整回答可替换选区、插入到选区后或复制。写回前继续校验草稿身份、选区位置和原始文本；上下文已变化时拒绝写回。Document 和 General 模式只允许复制。

## 错误分类与安全

### 服务端

服务端记录或解析上游错误后，只返回白名单化信息：

- `RATE_LIMITED`：上游 429 或已知限流错误码。
- `AUTH_FAILED`：401/403 或已知鉴权错误。
- `MODEL_NOT_FOUND`：模型不存在或无访问权限。
- `REQUEST_INVALID`：provider 拒绝请求参数。
- `UPSTREAM_TIMEOUT`：请求超时。
- `NETWORK_ERROR`：无法连接 provider。
- `STREAM_INTERRUPTED`：流未正常完成。
- `AI_FAILED`：无法安全分类的其他错误。

公开 SSE error 只包含稳定 `code`、本地化所需参数和可选 `retryAfterSeconds`。不得包含 provider 原始正文、URL、API Key、Vault 内容或堆栈。

### 前端

- 429 显示“请求过于频繁，请稍后重试”，支持按 `Retry-After` 倒计时。
- 倒计时结束或没有明确等待时间时显示“重试”按钮。
- 鉴权失败显示“模型凭证无效，请检查设置”并提供打开设置入口。
- 模型不存在提示检查模型名称。
- 超时、网络中断和流中断使用不同文案。
- 错误保留已生成的部分回答，但不显示替换、插入或复制操作。
- 重试复用原用户指令和原上下文前，必须重新确认上下文仍匹配；否则按当前上下文创建新请求。

## 请求诊断

- 后端只在本地进程日志记录安全诊断：错误分类、HTTP 状态、provider host、模型名和请求 ID。
- 日志不得记录 API Key、请求正文、消息内容或 provider 原始错误正文。
- 前端错误卡片可显示短请求 ID，便于对应本地日志。

## 测试

- 错误分类单元测试：429、401、403、404/模型错误、400、超时、网络异常、提前 EOF 和未知错误。
- 安全测试：provider 错误正文即使包含 API Key、URL 或 Vault 文本，公开事件与日志也不得泄露。
- 重试测试：倒计时、原请求重试、上下文变化后的安全重建。
- 布局测试：宽屏两列推开、320–560px 调宽、收起恢复、窄屏独立视图、reduced motion。
- 状态测试：打开侧栏不改变正文滚动位置；关闭后恢复焦点。
- 上下文测试：选区优先、无选区当前文档、无笔记 General，以及附带全文授权重置。
- 回归测试：多会话、请求所有权、selection 写回、对象同步、AI 整理和保存流程保持原行为。

## 非目标

- 不实现独立 Electron BrowserWindow。
- 不持久化会话或侧栏宽度。
- 不自动重试限流请求。
- 不向用户展示未经白名单化的 provider 错误。
- 不让 General 模式检索整个 Vault。
