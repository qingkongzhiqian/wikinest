# 桌面端导航与侧栏控制重构

## 目标

消除顶部浮动控件与搜索栏、macOS 原生标题栏之间的重叠，让侧栏折叠、展开和设置入口始终清晰、可点击、可发现。

## 已确认的交互

- Electron 桌面端使用独立标题栏，布局为“交通灯｜侧栏折叠”；不增加前进、后退按钮。
- 浏览器端仍在搜索工具栏中保留折叠按钮。
- 删除折叠按钮旁用途不清晰的下拉箭头和下拉菜单。
- 侧栏展开时，顶部按钮用于收起侧栏；侧栏收起时，同一位置的按钮用于展开侧栏。
- 设置入口固定在侧栏底部，与 MCP 状态区相邻；仅 Electron 桌面端显示。
- “更换知识库”放入设置弹窗，继续使用现有 IPC，不再占用顶部入口。
- 搜索框限制最大宽度并占据剩余空间，新建按钮保持在右侧。

## 布局

macOS 顶部使用 44px 自定义标题栏：

`[交通灯] [展开/收起] [可拖拽空白区]`

下一行保持纯内容工具栏：

`[搜索框（弹性、有限宽）] [新建]`

标题栏整行可拖拽，折叠按钮明确标记为 `no-drag`。侧栏展开时仍推动主体内容；窄屏沿用覆盖式侧栏。

侧栏底部：

`[MCP 状态] [设置齿轮]`

## 代码范围

- `src/web/page.js`
  - 移除 `#sideCtrl`、`#sideMenu`、`#sideMenuPop`。
  - 新增 `#desktopTitlebar`，将桌面端 `#sideCollapse` 放在交通灯右侧。
  - `.nav-inner` 保留仅供浏览器模式使用的折叠按钮。
  - 新增侧栏底部设置按钮。
  - 简化 `wireSidebar()`，保留折叠状态持久化。
  - 删除为固定控件预留空间的 CSS。
- `desktop/main.js`
  - 使用 `titleBarStyle: 'hidden'` 和明确的 `trafficLightPosition`，让 Web 标题栏负责拖拽与点击区域。
- 不改变后端 API、IPC 协议、Vault 切换方式或设置保存逻辑。

## 验收标准

- Electron 桌面端的折叠按钮可稳定点击。
- 桌面标题栏仅包含交通灯与侧栏折叠，不出现前进/后退按钮。
- 展开与收起两种状态下，按钮均不覆盖搜索框。
- 设置按钮在侧栏底部清晰可见，点击打开现有页内设置弹窗。
- 浏览器模式不显示桌面设置按钮，但侧栏折叠仍可使用。
- 现有测试和 lint 不新增错误。

## MCP 本地连接弹窗

- 侧栏底部改为两行操作：`● MCP 服务运行中`、`⚙ 设置`。
- 点击 MCP 行打开与设置弹窗同款的本地连接弹窗，不再直接复制。
- 弹窗只展示当前桌面 App 的本地地址，不涉及远程服务器或 Token。
- 内容依次为运行状态、本地 MCP 地址、Cursor JSON 配置、Claude Code 命令。
- 地址和两种配置均提供独立复制按钮；底部仅保留“关闭”。
- Claude Code 使用用户级命令：
  `claude mcp add --scope user --transport http wikinest-local http://127.0.0.1:4321/mcp`
