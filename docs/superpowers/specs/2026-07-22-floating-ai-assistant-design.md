# 悬浮 AI 助手设计

## 目标

将现有占据编辑区宽度的 AI 选区侧栏改为 Craft 风格的全局悬浮助手：平时仅显示在右下角的入口，展开后成为接近窗口高度的对话卡片，并根据当前页面自动使用笔记或编辑选区作为上下文。

## 交互形态

### 收起状态

- 所有主页面右下角显示圆形渐变 AI 入口。
- 入口固定在视口内，不随正文滚动。
- 未配置 LLM 时入口保持可见但禁用，通过提示说明需要配置 `LLM_*`。
- 面板展开时隐藏入口，关闭面板后恢复。

### 展开状态

- 宽屏下为右下角固定悬浮卡片，宽约 420px，高度为视口减去上下安全边距，最大高度约 760px。
- 卡片具有大圆角、轻阴影和不透明背景，不改变原页面宽度或编辑器布局。
- 窄窗口下卡片占据除安全边距外的大部分视口。
- 顶部依次为会话菜单、“新聊天”和关闭按钮。
- 中部展示快捷建议、消息历史和状态。
- 底部展示上下文卡片、输入框、发送、停止及上下文选项。

## 上下文模式

助手根据打开时及发送时的页面状态生成上下文快照：

1. **编辑选区**：编辑器存在非空选区时，以选区为主要上下文；可选择附带整篇草稿。完整回答支持替换选区、插入选区后和复制。
2. **编辑全文**：编辑器没有选区时，以当前草稿作为文档上下文进行问答，但不显示替换或插入操作，只允许复制。
3. **阅读笔记**：自动附带当前笔记 Markdown 正文，只提供问答和复制。
4. **无当前笔记**：在笔记列表、问答页等场景进行普通对话，不自动发送 Vault 内容。

每次发送都重新捕获页面、笔记路径、草稿身份、选区范围和正文，避免面板打开后上下文变化造成错配。写回仍使用既有选区快照校验；选区或草稿变化后拒绝替换和插入。

## 临时多会话

- 每条会话包含 ID、自动生成的简短标题、创建时间、更新时间、消息列表和最后使用的上下文摘要。
- 所有会话仅保存在当前页面运行内存中，不写入 Vault、不进入对象存储同步。
- “新聊天”创建空会话并切换过去，不清除其他临时会话。
- 左上角菜单展示最近更新的会话，可切换和删除。
- 关闭面板不取消已完成会话；关闭应用或刷新页面后全部清空。
- 正在生成时切换会话、关闭面板或离开对应上下文会取消当前请求，保留已收到的部分文本并标记为已停止。

## 快捷建议

空会话时根据上下文展示建议：

- 有编辑选区：润色、提升清晰度、缩短、扩写、修正拼写和语法、转 Markdown 表格。
- 有当前笔记但无选区：创建摘要、提取要点、生成表格、提出改进建议。
- 无文档上下文：隐藏文档编辑建议，仅展示普通提问引导。

快捷建议只填充并发送普通用户指令，不建立独立后端路径。

## 后端与数据流

扩展现有 AI 编辑服务为上下文对话服务，同时保留原选区编辑能力：

- 请求增加明确模式：`selection`、`document` 或 `general`。
- `selection` 要求非空选区；`document` 要求非空文档；`general` 不发送文档内容。
- 继续使用 OpenAI 兼容流式客户端和现有 SSE 协议。
- 继续执行输入裁剪：选区最多 16,000 字符，文档最多 32,000 字符，user/assistant 消息总量最多 48,000 字符。
- API Key 只留在 Node 后端；公开错误不包含 provider 响应、地址或密钥。
- 上游未发出完成信号便结束时仍视为中断，不产生可写回的完整回答。

## 安全与生命周期

- 模型内容始终以 `textContent` 显示。
- 只有状态为完成的回答可以复制；只有来自有效编辑选区快照的完成回答可以替换或插入。
- 一条回答成功应用后禁用重复应用。
- 同一时刻只允许一个流式请求。
- 面板关闭、会话切换、笔记切换、进入新草稿或离开对应上下文时取消请求。
- AI 写回只更新 textarea，并触发现有 `input`、预览和显式保存流程，不自动保存。

## 可访问性

- 悬浮入口、菜单、新聊天、关闭、发送和停止均有可翻译的可访问名称。
- 面板使用对话区域语义并管理打开/关闭焦点。
- Escape 关闭面板；Enter 发送，Shift+Enter 换行。
- 消息历史不是 live region，独立状态区域仅播报生成、完成、失败和停止状态。

## 测试

- 纯函数测试：上下文模式推导、会话创建/切换/删除/排序、请求所有权和选区写回。
- 服务测试：三种上下文模式的校验、裁剪和提示词。
- API 测试：三种模式的 SSE、公开错误、断连和提前 EOF。
- 页面测试：悬浮入口、卡片结构、响应式样式、上下文卡片、快捷建议及双语文案。
- 生命周期测试：关闭、切换会话、切换笔记和新建草稿取消请求；旧请求不能清理新请求状态。
- 回归测试：原选区替换/插入/复制、AI 整理、保存、预览和对象存储同步保持原行为。

## 非目标

- 不持久化或同步聊天记录。
- 不增加桌面端模型配置界面。
- 不实现可拖动、任意缩放或独立 Electron 窗口。
- 不让普通聊天自动检索整个 Vault；无当前笔记时不发送 Vault 内容。
